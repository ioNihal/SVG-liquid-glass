Refractive Glass

How SVG Liquid Glass Works

This project creates a liquid glass refraction effect using HTML, CSS, and SVG filters. Light appears to bend through an organic, curved surface.

Key Components

  • feTurbulence - generates fractal noise patterns
  • feGaussianBlur - smooths the noise for a liquid look
  • feDisplacementMap - bends pixels using the noise as a displacement map
  • backdrop-filter - adds the CSS glass morphism effect
  • JavaScript dragging - makes the card interactive

SVG Filter Breakdown

<filter id="light-bender"> <feTurbulence type="fractalNoise" baseFrequency="0.008" numOctaves="1" /> <feGaussianBlur stdDeviation="2" /> <feDisplacementMap scale="50" xChannelSelector="R" yChannelSelector="G" /> </filter>

Parameters

baseFrequency="0.008"
Controls the scale of the noise. Lower values give larger, smoother waves; higher values give more chaotic detail.
stdDeviation="2"
Controls blur smoothness. Higher values smooth the distortion; lower values preserve fine detail.
scale="50"
Sets the intensity of the refraction. Higher values bend light more dramatically.

Glass Card Color

The card uses a semi-transparent blue tint, rgba(225, 239, 255, 0.226), combined with:

  • An inner glow from an inset shadow
  • A subtle outer shadow for depth
  • CSS backdrop-filter for the browser-native glass effect
  • An SVG filter for the refraction itself

Interaction

  • Drag the card anywhere on the screen
  • Cursor shows grab on hover, grabbing while dragging
  • Background text animates continuously

Browser Support

  • Chrome and Edge: full support
  • Firefox: full support
  • Safari: full support
  • Internet Explorer: not supported

Performance Notes

The SVG filter is GPU-accelerated on modern browsers. For best performance:

  • Keep the filter region adjustment minimal
  • Avoid applying filters to large elements
  • Use transform: translateZ(0) for hardware acceleration
  • Test on target devices for frame rate consistency

Customization

  • Glass color: change the rgba(225, 239, 255, 0.226) value
  • More refraction: raise the scale attribute in feDisplacementMap
  • Smoother waves: lower the baseFrequency value
  • More liquid effect: increase stdDeviation
  • Text animation: edit the moveText keyframe
